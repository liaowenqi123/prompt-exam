# Prompt Exam · 提示词考试

朋友说他写的提示词比我好，说他是 Prompt 大师？这个世界还没有一个能测试提示词质量的东西——那就自己造一个。

**Prompt Exam 用真实场景 + 大模型评分，给提示词（prompt）打分。**

## 它是怎么工作的

1. 系统给出一个**真实场景**（内置 25 个场景库，也可用 AI 随机生成），比如"为一家新开的精品手冲咖啡店写开业宣传文案"。
2. 你写下你的**提示词**，提交考试。
3. **执行模型**严格按你的提示词，去完成这个场景任务，产出真实结果。
4. **评测模型**对照公开的评分标准（满分 100 分、8 个维度），结合"场景需求"和"实际产出"给你的提示词打分，并给出逐条理由和提升建议。
5. 支持**多场景模式**：一条提示词同时考 3~5 个场景，取平均分，检验你的提示词到底稳不稳。

## 评分标准（满分 100 分）

| 维度 | 分值 |
| --- | --- |
| 目标明确性 | 15 |
| 指令清晰性 | 20 |
| 上下文与背景 | 15 |
| 角色与受众 | 10 |
| 输出格式与结构 | 15 |
| 约束与边界 | 10 |
| 示例与示范 | 10 |
| 具体性与可执行性 | 5 |

完整标准在页面「评分标准」标签页可见，也会原样写入评测模型的提示词里。评分公开透明。

## 技术架构

- **前端**：React 18 + Vite（`web/`）
- **后端**：Node.js + Express 轻量代理（`server/`），把请求转发到任意 OpenAI 兼容的 `/chat/completions` 接口，并托管前端构建产物
- **模型**：默认 DeepSeek（`deepseek-chat`），可在页面右上角「模型配置」自由改为任意 OpenAI 兼容服务（含本地 LM Studio）

> 为什么需要一个小后端？因为绝大多数大模型 API 不允许浏览器跨域直连。代理保持极简：不做鉴权、不落盘，你的 API Key 由浏览器端保存、随请求转发，**只存在你自己的 localStorage 里**。

## 快速开始（本地开发）

```bash
npm install          # 安装根、server、web 三个工作区的依赖
npm run dev          # 同时启动后端(6666) 和前端(5173)
```

浏览器打开 http://localhost:5173 ，右上角「模型配置」里填入你的 API 地址 / Key / 模型即可。

### 用本地 LM Studio 测试

页面的「模型配置」里点 **「本地测试（LM Studio）」** 预设即可一键填好：

- API 地址：`http://localhost:30001/v1`
- API Key：`lm-studio`（LM Studio 不校验）
- 模型：`qwen/qwen3.5-9b`（按你本机加载的模型名修改）

> 不同模型名需要在「模型配置」里手动改成你本机加载的模型（在 LM Studio 的 Server 页面能看到）。

## 部署

**方式一：单端口部署（推荐）**

```bash
npm run build        # 构建前端到 web/dist
npm start            # 后端同时托管前端，监听 0.0.0.0:6666（可用环境变量 PORT 改端口）
```

把整个项目放到服务器上执行即可，访问 `http://<你的域名>:6666`。
监听 `0.0.0.0` 意味着本机和局域网内其它设备都能通过 `http://<本机IP>:6666` 访问。

**方式二：前端单独部署到静态托管（Vercel / Netlify / 对象存储等）**

只上传 `web/dist`，但此时需要配置 `web/vite.config.js` 的 `/api` 代理指向你部署的代理服务，或自行处理跨域。

### 部署时的 Key 配置

- 默认模型走 **DeepSeek 官方**接口，地址 `https://api.deepseek.com/v1`，模型 `deepseek-chat`。
- 你可以让用户自己在页面右上角「模型配置」里填自己的 Key；也可以把默认值改到任意网关/代理地址（例如公司内网网关），Key 留空由网关统一注入。
- API Key 位置已全部留成占位：前端配置面板可填，后端只转发、不存储、不落盘。

## 项目结构

```
prompt-exam/
├── server/          # Express 代理后端
│   └── index.js     # /api/chat 转发 + 静态托管
├── web/             # React 前端
│   └── src/
│       ├── lib/scenarios.js   # 25 个内置考试场景
│       ├── lib/scoring.js     # 评分标准 + 执行/评测提示词构造
│       ├── components/        # 配置面板 / 考试页 / 评分标准页
│       └── api.js             # 调用后端 /api/chat
└── package.json     # npm workspaces（server + web）
```

## 常见问题

- **提示「未配置模型」**：到「模型配置」里选一个预设或填好 Key。
- **本地 9B 小模型偶发不输出**：后端会自动重试，前端也会重试；仍失败请换更大的模型。
- **评测返回「评分解析失败」**：小模型偶发输出非法 JSON，前端已自动重试纠正；仍失败会展示原始输出便于排查。
